All for One is a tattoo shop in Richmond, VA. Because most of their traffic came from social media on mobile devices, the site was built around small-screen navigation first.

- Built from scratch using Grav CMS
- Mobile-first layout for visitors coming from social media

## Technical Focus

Used Grav CMS to give the shop an accessible back end for managing content while keeping the stack lighter than WordPress.
